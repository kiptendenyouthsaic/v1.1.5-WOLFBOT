

# WOLFBOT

WOLFBOT is a WhatsApp automation bot powered by `wolfsocket` and `wolfbtns`.
It includes group management, status tools, media utilities, automation, AI
commands, and persistent configuration support.

## Run

1. Install Node.js 22 or newer.
2. Install dependencies with `npm install`.
3. Configure `SESSION_ID` and other settings in the environment.
4. Start the bot with `npm start`.

The primary entrypoint is `index.js`. Keep credentials and database URLs out of
the repository.
